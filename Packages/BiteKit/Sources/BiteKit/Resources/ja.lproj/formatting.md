# 書式
行の先頭で次のように入力します：
- `#` とスペースで見出し
- `-` とスペースで箇条書き、`1.` とスペースで番号付きリスト
- `[]` または `【】` でToDo
- `>` とスペースで引用
- `---` で区切り線、バッククォート3つでコードブロック

`**` で囲むと**太字**、`*` で*斜体*、`~~` で~~取り消し線~~、バッククォートで`コード`になり、`[テキスト](アドレス)` でリンクになります。テキストを選択してスタイルを選ぶこともできます。

> 中身はすべてプレーンな Markdown で、コピーしても Markdown のままです。
